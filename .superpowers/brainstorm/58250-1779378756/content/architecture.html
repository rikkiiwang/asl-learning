Session loop (orchestration)

Login → Progress dashboard (overview of mastery + recent history)
Start session → create sessions row → camera check + framing guide
Fetch mastery-prioritized deck (~10 words: not-mastered first + a couple reviews)
Per word: show prompt → countdown → record 2s → infer → decide
PASS → log attempt → advance  ·  FAIL → hint → retry; after ~2–3 fails offer reference clip; Skip allowed
Every capture writes an attempts row → DB trigger updates sign_mastery (2 first-try passes across sessions = mastered)
End session → set ended_at → summary (mastered / accuracy) → deck re-prioritizes next time
